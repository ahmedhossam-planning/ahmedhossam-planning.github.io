04 / CONSTRUCTION SEQUENCE

How the sequence
holds together.

The typical sequence structure behind each project type in the register.

01

Education / access

Release rooms → protect occupied areas → demolition → MEP / finishes → QA and handover.

02

Water / process trains

Bypass and isolate → execute piping/equipment work → ORT / FST → acceptance → next train.

03

Data centers / MEP

Approved submittals → manufacturing / kits → install → flush / energize → commissioning / RFS.

04

Highways / phases

Detours → drainage and earthwork → paving / electrical → traffic switch → inspections.

05

Federal facilities

Permission to proceed → procurement → zone renovation → systems testing → closeout.

06

Vertical buildings

Structure per floor → MEP and enclosure → interiors → testing → area turnover.
